# Мара — канонический визуальный промпт

Этот файл фиксирует основной образ персонажа Мара для будущих генераций изображений.

## Канонический образ

Мара — стройная молодая женщина, изображённая в минималистичной монохромной графике, ближе к аккуратному карандашному/чернильному character sheet.

### Внешность
- длинные тёмные волосы, аккуратно причёсанные;
- глаза открыты;
- лицо спокойное, уверенное, без излишней гламурности;
- на голове венок из ромашек, переплетённых с **хорошо узнаваемой колючей проволокой**;
- естественные пропорции тела;
- стройное телосложение.

### Одежда
- светлая спортивная олимпийка на молнии;
- контрастные полосы вдоль рукавов;
- светлые спортивные/карго-брюки с накладными боковыми карманами;
- манжеты на щиколотках;
- простые спортивные кроссовки.

### Стиль
- монохромная графика;
- чистые линии;
- лёгкая штриховка;
- минимум лишних деталей;
- белый или очень светлый фон для референс-листов;
- сохранять одинаковое лицо, причёску, венок, одежду и пропорции на всех ракурсах и позах.

## Основные позы
- анфас;
- профиль;
- ходьба;
- шаг в сторону;
- широкий шаг;
- поворот при ходьбе;
- бег;
- сидя;
- на корточках.

## Эмоции — портрет по плечи
Использовать отдельную линию из шести основных выражений:
1. радость;
2. грусть;
3. злость;
4. страх;
5. удивление;
6. спокойное / нейтральное выражение.

## Реквизит
Отдельными предметными референсами могут использоваться:
- еловая ветка;
- аэрозольный баллон;
- перцовый баллончик;
- нож;
- пистолет ПМ как визуальный реквизит;
- рюкзак.

## Правила для будущих изображений
- не менять базовое лицо без отдельной просьбы;
- волосы по умолчанию аккуратно причёсаны;
- глаза по умолчанию открыты;
- колючая проволока на венке должна сразу читаться визуально;
- по умолчанию сохранять минималистичную чёрно-белую эстетику;
- для динамических сцен сохранять узнаваемость персонажа и естественную пластику;
- если пользователь говорит «Мара» без дополнительных уточнений, использовать этот образ как основной.
